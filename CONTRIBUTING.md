# Contributing Guide for this Project

Thanks for considering contributing to our project to make it better! We value help and quality code. However, to keep everything safe and under control, we have some ground rules.

1. **Be Respectful** Do not make any derogatory remarks for anyone in the community.
2. **Do not Sabotage** We do not appreciate ill-minded PRs.
3. **Communicate Clearly** We expect contributors to write readable code and good PRs communicating the changes clearly.
4. **Do not take this lightly** I mean it.

## How to contribute?

If contributing on an already open issue, ask yourself to be assigned and discuss the changes with the maintainer. If you are a contributor and want to make some changes, fork this repository, make changes in a new branch and test them properly before sending us a PR. All notebooks should be in the notebook directory, datasets in data directory and code in the src directory.

## Nature of this project

We are creating this for a course assignment. It's not something very professional so just don't mess things up; that'll be enough.
